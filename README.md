# 使用 ASP.NET 1.1 进行 Web 开发

➡️ **在线课程：**
[使用 ASP.NET 1.1 进行 Web 开发](https://stahe.github.io/zh-aspnet1.1-avril-2004/)

## 简介

本文档是一份面向学生的**教学资源**，并非旨在提供全面的课程。某些主题需要教师的指导，且网络开发的多个方面已被有意省略。

本资源属于一系列关于**Web开发**的文档，作者此前已通过以下两种技术对该主题进行了深入探讨：

* **Java**
* **PHP**

这些文档采用**相似的教学结构**，便于通过类似的示例对不同技术进行比较。

## 教学方法

与许多关于 ASP.NET 的书籍不同，本资源并未直接聚焦于“ASP.NET Web 应用程序可作为 **Windows 应用程序** 进行开发”这一理念。

在传统的 ASP.NET 文献中：

* 用户界面通常在 **Visual Studio .NET** 或 **WebMatrix** 等集成开发环境（IDE）中实现
* **图形控件**被放置在可视化界面中
* 这些控件具有**属性、方法和事件**

在本文档中，这些概念被有意安排在**课程后半部分**介绍，因为虽然它们很重要，但对于理解Web开发而言**并非基础**。

## 主要目标

本文档的前半部分侧重于**Web开发的基础知识**，无论使用何种技术（Java、PHP 或 ASP.NET）。

特别关注架构：

**MVC — 模型 / 视图 / 控制器**

这种架构通常被推荐用于设计结构化且易于管理的 Web 应用程序。

然而，MVC 方法与 ASP.NET 将 Web 应用程序设计为 Windows 应用程序的理念相对不兼容。因此，旨在提高生产力的 ASP.NET 特定机制将在 **课程的第二部分** 中进行讲解。

## 使用的工具

本文档仅关注**互联网上可免费获取的工具**，以便学员能够：

* 轻松下载；
* 在个人计算机上安装环境；
* 复现并尝试课程中的示例；

附录**“Web 工具”**详细说明了如何获取并安装这些工具。
